# Zenka Launcher

Um launcher moderno, minimalista e eficiente para Android. Inspirado pela simplicidade e pela busca rápida.

## Objetivo
Criar uma experiência de home screen ultra-leve que prioriza a agilidade na descoberta de apps, com consumo mínimo de bateria e desempenho fluido.

## Estrutura
- `src/components`: Componentes de UI (barras de busca, grids de apps, gestos).
- `src/hooks`: Lógica de estado e interação com o sistema.
- `src/services`: Lógica de aprendizado de uso e integração nativa.
- `src/theme`: Sistema de design (cores, espaçamentos, tipografia).

## Como rodar
1. `npm install`
2. `npx expo start`
